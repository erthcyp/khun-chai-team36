# Pitch notes (target: 3–5 min)

1. **Hook / problem** (30s) — a real person, a real number.
2. **Solution** (30s) — one sentence.
3. **Live demo** (2 min) — happy path only. Backup video ready.
4. **Why AI-native / which track** (30s)
5. **How we built it with Codex** (30s) — see codex-log.md
6. **Impact & next steps** (30s) — practical + responsible for users/businesses/communities

## Likely judge questions
- What happens when the agent gets unexpected input?
- Who pays / who uses this tomorrow?
- What's real vs mocked in the demo?
